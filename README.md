🍕 Pizza Sales Analysis

Project Overview

This project analyzes pizza sales data using SQL Server and Power BI to understand business performance, sales trends, and customer ordering patterns.

Tools Used

- SQL Server Management Studio (SSMS)
- Microsoft Power BI
- SQL

Dataset Tables

- Orders
- Order Details
- Pizzas
- Pizza Types

Key Business Insights

KPI| Result
Total Revenue| 817,860.05
Total Orders| 21,350
Total Pizzas Sold| 49,574
Average Order Value| 38.31

SQL Analysis

1. Data Checking
2. Top 10 Pizza Project Details
3. Total Orders, Pizzas Sold and Revenue
4. Total Rows in Tables
5. Category-Wise Sales
6. Monthly Sales
7. Top 5 Best-Selling Pizzas
8. Bottom 5 Least-Selling Pizzas

Power BI Dashboard

Created a dashboard to display:

- Total Revenue
- Total Pizzas Sold
- Average Order Value
- Pizza Sales by Category

Project Objective

The main objective is to analyze pizza sales data and present useful business insights through SQL queries and an interactive Power BI dashboard.
